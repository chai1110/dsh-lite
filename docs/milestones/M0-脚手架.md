## 0. 开工前置（必须先拍板）

M0 本身不依赖 DSH 协议，但**配置项会写进 `package.json`**，所以先定三条（详见 `05-开发总规划.md` §3.5）：

1. **端口**：默认 `3082`（`advanced.port`），与 0.5.1 的 3080、用户已有 3081 错开 → 影响 §4.4 配置表
2. **会话写入边界**：只读他人会话，只写 Lite 自己创建的 → 影响 M3，M0 只需知道**不需要额外配置**
3. **cwd 归属**：新建会话以工作区根为 cwd，历史按 cwd 客户端过滤 → M0 只需预留 `workspaceRootIndex`

三条已按推荐值写入本文，若你不同意请在此阶段提出，改起来成本最低。

## 1. 目标 / 非目标

### 目标
1. 一个能安装、能激活、能在侧栏显示空白面板的扩展骨架

## 4. `package.json` 贡献点（严格按白名单）

### 4.1 标识与激活
```jsonc
{
  "name": "dsh-lite",
  "publisher": "chai1110",
  "displayName": "DSH Lite",
  "main": "./out/extension.js",
  "activationEvents": [
    "onView:dshLite.panel",
    "onCommand:dshLite.openSidebar"
  ]
}
```
> 只留 2 个激活事件。0.5.1 有 13 个，我们**不预注册未实现的命令**（避免命令面板出现空壳）。

### 4.2 视图（沿用 0.5.1 已验证形式）
```jsonc
"viewsContainers": {
  "activitybar": [{ "id": "dshLite", "title": "DSH Lite", "icon": "assets/icon.svg" }]
},
"views": {
  "dshLite": [{ "id": "dshLite.panel", "name": "DSH Lite", "type": "webview" }]
}
```
- 图标：先用占位 SVG（不复用 0.5.1 的鲸鱼图标，避免视觉混淆两个插件）

### 4.3 命令（M0 只注册 2 条，其余随阶段启用）
| 命令 | M0 | 启用阶段 |
|---|---|---|
| `dshLite.openSidebar` | ✅ | M0 |
| `dshLite.openInBrowser` | ⏸ | M1 |
| `dshLite.newSession` | ⏸ | M3 |
| `dshLite.addSelection` / `addFile` | ⏸ | M3 |
| `dshLite.stop` | ⏸ | M3 |
| `dshLite.acceptChanges` / `rejectChanges` | ⏸ | M4 |
| `dshLite.showLogs` | ⏸ | M5 |

### 4.4 配置（6 + 1，全部宿主行为）
| 配置 | 类型 | 默认 | 阶段 |
|---|---|---|---|
| `dshLite.executablePath` | string | `""`（自动探测） | M1 |
| `dshLite.autoStart` | boolean | `true` | M1 |
| `dshLite.openOnStartup` | boolean | `false` | M1 |
| `dshLite.composerEnterBehavior` | `send` \| `newline` | `send` | M3 |
| `dshLite.followUpQueueMode` | `queue` \| `steer` | `queue` | M3 |
| `dshLite.workspaceRootIndex` | number | `0` | M3 |
| `dshLite.advanced.port` | number | `3082`（占用则回退） | M1 |
| `dshLite.advanced.logLevel` | `error\|warn\|info\|debug` | `info` | M5 |

> **校准说明（2026-09-07）**：初版漏了 host/port。结论是 **host 固定 `127.0.0.1` 不配置**（只连本机、不复用外部实例），**端口放 `advanced.port`**（默认 3082，与 0.5.1 的 3080、用户已有 3081 错开），从而维持「6 主配置 + 1 高级分组」的形态。

> M0 就**一次性声明全部配置**（声明不等于实现），避免后续 `package.json` 频繁变更；未实现的项在 UI 中不出现。

## 5. 构建方案（esbuild 双 bundle）

`scripts/build.mjs`（移植自 0.5.1，扩展为两个入口）：

| 入口 | 产物 | 平台 | 说明 |
|---|---|---|---|
| `src/extension.ts` | `out/extension.js` | node, cjs | `external: ['vscode']` |
| `webview/index.tsx` | `out/webview.js` | browser, iife | 打包 React，产出单文件供 webview 引入 |

**脚本能力**
- `npm run compile` —— 构建两个 bundle
- `npm run watch` —— `--watch`
- `npm run typecheck` —— `tsc --noEmit`
- `npm test` —— 先构建再 `node --test "out/test/**/*.test.js"`
- `npm run package` —— `compile` + `vsce package -o dsh-lite.vsix`

**Webview 资源引用**：用 `webview.asWebviewUri()` 生成 `out/webview.js` 与 `styles.css` 的 URI；`enableScripts: true`，`localResourceRoots` 限定为 `out/`。

**CSP**：`default-src 'none'; script-src <cspSource> 'nonce-<随机>'; style-src <cspSource> 'unsafe-inline'; img-src <cspSource> data:`（沿用 0.5.1 的 nonce 方案，nonce 每次渲染随机生成）

## 6. Webview 骨架（M0 只画"三行框架"）

```
┌ 顶栏 ──────────────────────────┐   ← 会话下拉 / ＋ / ⋯（M0 为禁用占位）
├ 消息区（占满剩余）──────────────┤   ← 空态文案「尚未连接」
└ 输入区 ───────────────────────┘   ← 输入框（禁用）
```

- 样式**只用 `--vscode-*` 变量**（`--vscode-sideBar-background`、`--vscode-foreground`、`--vscode-font-family`、`--vscode-button-background` 等），确保明暗主题自动跟随
- M0 验收点之一：切换 VS Code 明暗主题，三行框架颜色正确变化

## 7. 宿主 ↔ UI 协议 v1（骨架）

`src/panel/protocol.ts` 定义，webview 与宿主共用类型：

```ts
export const PROTOCOL_VERSION = 1;

// UI → 宿主
export type UiMessage =
  | { type: 'hello'; protocolVersion: number }     // UI 启动后先握手
  | { type: 'ui/ready' };

// 宿主 → UI
export type HostMessage =
  | { type: 'hello'; protocolVersion: number }                     // 握手回执
  | { type: 'host/state'; state: PanelState }                      // 状态快照
  | { type: 'host/error'; code: string; message: string };

export interface PanelState {
  connection: 'idle' | 'connecting' | 'ready' | 'error' | 'offline';
  sessions: SessionBrief[];      // M2 填充
  messages: ViewMessage[];       // M2 填充
}
```

**版本不匹配处理**：宿主发现 UI 的 `protocolVersion` 低于自身 → 显示「请重载窗口以更新面板」；高于自身 → 提示升级插件。**绝不静默降级**。

> M0 只实现 `hello` 握手 + 一个 `idle` 状态快照；`sessions`/`messages` 字段先给空数组。

`npm install` 在本沙箱被拦截（`CODEBUDDY_BROKER_DENY`），且 `@vscode/vsce` 会触发该错误。

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| esbuild 打包 React 时 JSX 配置踩坑 | 先在最小样例里验证 `jsx: automatic`；不行就退回 `React.createElement` |
| webview 资源加载被 CSP 拦 | 严格用 `asWebviewUri` + nonce；先在 M0 就跑通，避免 M2 再排查 |
| 与 0.5.1 的 activitybar 图标混淆 | 用不同图标；容器 id 独立（`dshLite` vs `dsh`） |
| 双 bundle 让 build.mjs 复杂度上升 | 两个 entry 配置独立对象，互不复用；保持脚本 <150 行 |
